The OEDI-SI Platform

OEDI-SI

OEDI-SI (Open Energy Data Initiative — System Integration) is an orchestration interface for HELICS power-system co-simulations. It lets you wire independent simulation components (feeders, state estimators, optimizers, recorders) into a co-simulation, run them, and analyze the results — either from a drag-and-drop web UI or directly from the oedisi command line.

What OEDI-SI gives you

  • A component framework that instantiates each algorithm as a HELICS federate with the correct publications, subscriptions, and configuration.

  • A web application to assemble, run, and visualize simulations without writing code.

  • Shared Pydantic data models (oedisi.types) so components exchange voltages, powers, and topology in a common language.

  • A CLI and multi-container workflow for reproducible and distributed runs.

Choose your path¶

🟢 Beginner

Use the web UI. Run existing templates, browse the component catalog, and read your results — no coding required.

🟡 Intermediate

Build your own component, register it so it appears in the UI, and run a simulation that uses it.

🔴 Advanced

Drive OEDI-SI from the Python API and CLI, and scale out with the multi-container (Docker / Kubernetes) workflow.

In a hurry?¶

Jump straight to the 5-minute quickstart to install the app and run your first simulation, or see how OEDI-SI works for the mental model.

Source repositories

OEDI-SI spans three repositories:

  • oedisi — the framework, types, and CLI.

  • oedisi-components — reusable HELICS components.

  • oedisi-frontend-app — the web UI and backend.
